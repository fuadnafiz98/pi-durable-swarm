01 · BIG PICTUREWhat goes in, and what comes out?

You write a page folder: the words in body.html, the drawings in figures.js. build.py turns it into one HTML file with nothing to download. check.mjs clicks through every figure and screenshots each state. Hover any box.

02 · WORKFLOWIn what order is a page made?

Facts before pictures, pictures before code. Each stage has an output you can point at, and the next stage starts from it.

03 · STRUCTUREWhat is a built page made of?

Layers, each resting on the one below. The code panes are a layer of their own: present only when the reader asked for code.

04 · WHERE IT RUNSWhere does each part run?

Three places: your machine builds and checks, the artifact host stores the page, the reader's browser runs it. Step through one page's trip.

05 · STATEHow does a playing figure behave?

A clock figure is a small state machine. Pick a state to see where it can go next.

06 · OVER TIMEWhat does one round of build and check look like?

Three rounds you will meet. The clock plays and stops at each event.

07 · CALL STACKWhat runs when you build with --code?

The frames on the stack at each moment, bottom to top. The top frame is the one running.
